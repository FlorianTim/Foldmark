# Brand assets

The supplied assets are editable draft SVGs using only vector paths, shapes and system-font text. Convert text to paths before a final trademark/logo release if exact rendering across environments is required.

Files:

- `foldmark-mark.svg`: colored logo mark on paper background
- `foldmark-logo-horizontal.svg`: wordmark and Lambro Code attribution
- `foldmark-mark-monochrome.svg`: currentColor single-color variant
- `foldmark-app-icon.svg`: app/PWA icon draft
- `foldmark-social-card.svg`: social/repository preview draft
- PNG previews are generated from the SVGs for convenience
