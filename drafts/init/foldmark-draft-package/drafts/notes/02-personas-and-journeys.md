# Personas and primary journeys

## Persona A — private correspondent

Needs a one-off formal letter, chooses a saved sender, enters a recipient, writes Markdown, sees an A4 preview with fold marks and prints or saves as PDF.

## Persona B — club secretary

Maintains several sender profiles, address templates and recurring documents. Wants local persistence, search, reusable letter templates and exported backups.

## Persona C — postcard creator

Imports a local photo for the front, writes a message on the back, enters a postal address in the correct area and exports a duplex PDF.

## Persona D — privacy-conscious professional

Requires a network-silent default app, clear data inventory, local deletion/export and explicit consent before Drive or Contacts integration.

## Persona E — advanced user

Creates a custom print profile with page size, margins, markers, content boxes and preview-only guides.

## Core journeys

### Create and print a letter

1. New document → Letter
2. Select sender and recipient
3. Select built-in or custom print profile
4. Enter subject/date/body
5. Validate the document for print
6. Review physical preview at 100% scale
7. Print or save PDF

### Email a letter

1. Open an existing letter
2. Choose Email handoff
3. Select text, HTML, PDF-for-email or EML
4. Choose whether to include graphical signature
5. Remove fold marks by default for email PDF
6. Open mail client, share file or download EML

### Create a postcard

1. New document → Postcard
2. Select size and duplex profile
3. Add front image/text
4. Fill back message and address
5. Validate stamp/address/safe areas
6. Export front/back pages in documented print order

### Enable a connector

1. Open Privacy & Connections
2. Inspect requested scopes and data flow
3. Explicitly activate capability
4. Load connector code only after consent
5. Authenticate with PKCE
6. Use connector for a user-initiated action
7. Disable connector and clear tokens
