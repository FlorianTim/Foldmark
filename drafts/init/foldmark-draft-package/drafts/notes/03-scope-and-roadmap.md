# Scope and roadmap

## MVP

- Vue application shell with German/English localization and multiple local themes
- Markdown editor plus structured forms for metadata
- YAML front matter import/export
- local documents in IndexedDB
- local address book and multiple sender profiles
- built-in A4/DIN-style letter profiles and blank A4/A5
- configurable marker renderer for fold/hole/cut/safe/bleed/custom guides
- browser print and Save-as-PDF workflow
- profile-aware validation and actionable warnings
- privacy center, local data export/delete and third-party notice page
- local graphical signature import/drawing placeholder
- no third-party requests during normal startup

## Release 1.x

- EML export
- HTML/plain-text email renderers and mailto handoff
- postcard A6 front/back and duplex PDF workflow
- local images, logos and letterhead assets
- custom print-profile editor
- document templates and recent documents
- import/export of complete encrypted or plain backup packages

## Later optional capabilities

- Google Drive open/save
- Google Contacts import/search
- File System Access API enhanced saving
- Web Share API
- ODT export
- controlled direct PDF generation
- address lookup APIs with explicit consent
- advanced visual layout editor
- WebDAV or other open storage adapters

## Deferred/not MVP

- backend accounts
- server-side SMTP
- collaborative editing
- cryptographic qualified signatures
- full PDF editing
- permanent cloud synchronization
- analytics and advertising
- a hard paywall around the core print-marker functionality
