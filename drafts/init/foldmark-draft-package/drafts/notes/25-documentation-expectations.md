# Documentation expectations

The initializer should derive and maintain:

- OpenSpec project and capability specs
- OpenSpec changes per implementation slice
- arc42 architecture documentation
- ADRs for canonical format, print profile model, storage, privacy, export strategy and capability system
- Mermaid system/context/runtime diagrams
- PlantUML domain/class diagram
- data inventory and external request register
- threat model and abuse cases
- README with screenshots, local build, deployment and privacy statement
- third-party notices and license policy

Generated diagram images may be build artifacts, but `.mmd` and `.puml` sources are authoritative and versioned.
