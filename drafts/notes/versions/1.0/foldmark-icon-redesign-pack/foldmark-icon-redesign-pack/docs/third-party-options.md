# Optionale Drittanbieter-Basis

Dieses Paket enthält bereits eigene SVG-Assets. Falls das Team zusätzlich auf eine
freie Icon-Bibliothek zurückgreifen möchte, sind die naheliegendsten Kandidaten:

- **Lucide**: sehr saubere Line-Icons, gute Vue-Unterstützung, ISC-Lizenz
- **Tabler Icons**: große Auswahl, 24x24 Grid, MIT-Lizenz
- **Heroicons**: solide UI-Grundversorgung, MIT-Lizenz
- **Material Symbols**: besonders groß und flexibel, Apache-2.0-Lizenz

Empfehlung:
- Eigene Marken- und fachspezifische Symbole (Foldmark, Lambro Code, Falzlinien,
  Wasserzeichen, Signatur, Mail-Modi) lokal behalten.
- Für generische Standardaktionen kann das Team bei Bedarf eine der Bibliotheken als
  Ergänzung nutzen.
