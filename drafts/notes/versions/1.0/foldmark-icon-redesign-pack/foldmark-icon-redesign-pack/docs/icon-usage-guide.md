# Icon Usage Guide

Dieses Dokument ist die Kurzbeschreibung für den Coding-Agent.

## Global / Header

| Icon | Primärer Zweck | Hinweise |
|---|---|---|
| `foldmark-mark` | App-Logo | im Header, About, ggf. Favicon-Ableitung |
| `lambrocode-mark` | Unternehmens-/Website-Logo | bei Links zu Lambro/Lumbre Code |
| `language` | Sprachumschalter | neben Dropdown oder als Prefix-Icon |
| `theme-cycle` | Theme-Switcher | klickt zyklisch durch die Themes |
| `menu` | Mobile-Menü | nur im schmalen Layout |
