# Concrete-app feedback

Use the repository skill at `.github/skills/capture-template-feedback/SKILL.md` when generation,
initialization, building, testing or deployment exposes a reusable template problem. Create one
sanitized entry per problem under this directory, then propose the smallest generic change to the
original template through its normal pull-request workflow.

Feedback must identify the source template version, concrete-app version, reproducible symptom, root
cause, workaround, proposed template improvement, security/privacy implications and verification
evidence. Remove credentials, customer data, internal URLs and unrelated application details.
