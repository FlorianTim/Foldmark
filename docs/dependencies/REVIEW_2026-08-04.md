## Deliberately deferred majors

- **TypeScript 7:** `typescript-eslint` 8.66.0 declares TypeScript `<6.1.0`; upgrading would create
  an unsupported peer graph. TypeScript remains at 5.8.3 until the lint/typecheck ecosystem supports
  a newer stable major.
- **Pinia 4:** the template stays on 3.0.4 because the current API is sufficient and a state-library
  major deserves a focused migration and persistence regression review.
- **ESLint 10:** 9.39.5 is the registry's maintenance line. A major flat-config migration provides
  no security benefit for this release and would raise the minimum Node patch level.
  `npm audit --audit-level=high` must report zero unresolved vulnerabilities before publication.
- **Node types 26:** the declarations stay on the Node 24 line because Node 24 is the pinned
  runtime. Raising type declarations ahead of runtime would make unavailable APIs appear valid.
