# Requirements roadmap

The current specification view for Foldmark, derived from the material in `drafts/init/` and the
post-1.0 feedback in `drafts/notes/Foldmark_V1.0_Feedback_Redesign_2026-09-11.md` and the testing
round in `drafts/notes/versions/1.0/Foldmark_V1_Postrelease_Anforderungen_2026-09-13.md` and the
second test round in
`drafts/notes/versions/1.0/Foldmark_V1_Korrekturen_Roadmap_Premium_2026-09-16.md`. Raw ideas stay
non-normative until accepted through OpenSpec.

The MVP below was planned as 0.1 and ships as `1.0.0`. The 1.x sections use that numbering; the
earlier 0.2/0.3 slices are kept as candidates and are scheduled from there.

### 0.1 — MVP (implemented)

| ID      | Requirement                                                                                                    | Priority |
| ------- | -------------------------------------------------------------------------------------------------------------- | -------- |
| R01-001 | A document carries content and metadata and never physical geometry.                                           | Must     |
| R01-002 | Print profiles describe page size, margins, regions and helper markers in millimetres.                         | Must     |
| R01-003 | Preview and print render from one deterministic render plan; display zoom cannot affect an export.             | Must     |
| R01-004 | Built-in profiles are immutable, deep-frozen, and declare their standards-verification status.                 | Must     |
| R01-005 | Documents export and re-import as Markdown with YAML front matter without material loss.                       | Must     |
| R01-006 | Untrusted front matter is parsed by a bounded subset that refuses anchors, aliases, tags and flow collections. | Must     |
| R01-007 | Validation is target-aware and graded into errors, warnings and notes.                                         | Must     |
| R01-008 | Documents, addresses, sender identities, profiles and images persist locally and survive reload.               | Must     |
| R01-009 | The privacy view counts stored data, exports all of it, restores it and deletes it.                            | Must     |
| R01-010 | Startup makes no intentional third-party request.                                                              | Must     |
| R01-011 | German and English are complete, with matching key sets and placeholders.                                      | Must     |
| R01-012 | No HTML is generated from document text in any renderer.                                                       | Must     |
| R01-013 | Mail header values are refused, never repaired, when they carry a control character.                           | Must     |
| R01-014 | Image import validates the decoded bytes, not the declared type.                                               | Must     |
| R01-015 | A6 postcards have a front and a back and export in a documented print order.                                   | Should   |
| R01-016 | The profile view shows every marker coordinate in millimetres.                                                 | Should   |
