# Design: 1.0 post-release regressions

| Decision                                                               | Alternative rejected                             | Why                                                                                                                                |
| ---------------------------------------------------------------------- | ------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| Close the dialog before `print()`, reopen after `afterprint`           | Only `@media print { dialog { display: none } }` | Chrome renders the top layer separately; a `display: none` rule is not honoured for an open modal in every version. Both are done. |
| Object URL resolved in the node view, placeholder box until it arrives | Resolve before creating the node                 | The node must exist synchronously (ProseMirror transaction); an empty `src` collapsed the element and hid the insertion.           |
| Plain-text renderer stays a pure function over the block model         | Post-process the Markdown string with regexes    | The block model already has no syntax; the leak came from `*` bullets and pipe tables, fixed at the source.                        |
| Guides toggle hides `preview && !print` markers only                   | Hide every marker (1.0)                          | A user hiding _guides_ still expects the fold marks that print; hiding them made the preview disagree with the paper.              |
| Library list generated by `licenses:generate` as JSON                  | Parse the Markdown notices in the browser        | The generator already knows name, version and licence; a JSON next to the notices needs no parser in the app.                      |
| Preview scrolls only on an explicit page selection                     | `scrollIntoView` on every `surfaceIndex` change  | The watch fired on re-render and dragged the scroll position; it now fires only from the page navigator.                           |

## Chrome print

`OutputDialog.print()` closes the native dialog, waits for the next animation frame (layout flush),
calls `window.print()`, and restores the dialog when `afterprint` fires or synchronously after
`print()` returns in Firefox. `print.css` adds
`dialog, [popover], .app-menu-panel { display: none !important }` under `@media print`.

## Image insertion

`imageView` in `foldmarkSyntax.ts` builds the `<img>` and asks `resolveAssetUrl(assetId)`. In 1.0
the element had no `src` while the promise was pending; Chrome renders that as a zero-size box, and
an insertion at the very end of the document was invisible until the next transaction. The view now
carries `md-image-loading` with the requested width until the URL arrives, and the insert command
wraps the image in a paragraph of its own when the selection is at the end of the document.
`RichTextEditor` reloads the asset list after an import from the dialog.

## Guides

`visibleScreenMarkers(page, showGuides)` becomes `page.markers.filter(m => m.print || showGuides)`:
printed marks are always drawn on screen, preview-only guides follow the toggle. The print copy
keeps a `paper`-mode plan that only contains printed marks, unchanged.

## Preview scrolling

The `surfaceIndex` watch scrolled on every change, including the reset to 0 on each document change
and profile switch. Scrolling now happens in `selectPage`, called from the page navigator only; the
`ResizeObserver` callback compares the new size with the stored one before writing, so a scroll
inside the viewport (which fires no resize) never re-measures.
