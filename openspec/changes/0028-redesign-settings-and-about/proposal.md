# Proposal: Settings in categories, document defaults, data management; About and open-source view

Status: Implemented (2026-09-15). Source:
`drafts/notes/versions/1.0/Foldmark_V1_Postrelease_Anforderungen_2026-09-13.md` §18–§19, §59, Phase
G 3–6. Roadmap R13-032, R13-008 (second half).

## Scope

- Settings as a category list (General, Documents, Appearance, Fonts & colours, Date & language,
  Storage & history, Privacy, Data & backup, Development, About) with a side navigation on wide
  screens and stacked sections on phones.
- Document defaults: language, date format, print profile, font family, size, line height, paragraph
  spacing, page numbers — read by `workspace.create`.
- Data management: delete documents / contacts / assets / history / all local data, each with its
  own confirmation; the privacy view keeps the inventory and backup.
- Open-source view: table of libraries (name, version, licence, link), runtime and development
  grouped, generated by `licenses:generate`; legal links stay placeholders in dev and point to the
  LumbreCode pages in production (`publicResources`).

## Acceptance

Settings render every category; document defaults apply to a new letter (unit test on
`documentDefaults.ts`); each delete action removes only its collection (service tests).
