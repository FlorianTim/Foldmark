# Proposal: Add the LumbreCode distribution and compliance baseline

## Motivation

Concrete apps need deterministic LumbreCode domains, portable releases, versioned product planning,
safe dependency maintenance, discoverable privacy controls and a feedback loop into the template.
The Todo demo also needs a safe Markdown example without introducing an HTML trust boundary.

## Scope

- Resolve `<slug>.webapps.lumbrecode.de` and canonical public documentation links.
- Build identical local and hosted static ZIP releases with checksums.
- Add version, changelog, idea-roadmap and concrete-app feedback conventions.
- Strengthen privacy, crawler, dependency provenance and EU release guidance.
- Add direct local-data deletion and a non-HTML Todo Markdown subset in German and English.

## Out of scope

- A legal guarantee independent of concrete app behavior and hosting.
- Client-side claims that an automated visitor can reliably be distinguished from a human.
- Production authentication, DNS changes, mailbox provisioning or a bot-detection provider.
