# Internationalization

## Requirement

German and English are complete for all shipped UI. The interface language is independent of the
**document** language: a German interface may hold an English letter, and dates on a document are
formatted in the document's own locale in UTC.

No user-facing prose is produced in the domain or application layers. Validation findings, errors
and layout labels travel as translation keys with bounded parameters, and the presentation layer
resolves them. A message catalogue is one JSON file per locale with matching key sets.

## Verification

- `tests/i18n.test.ts` covers locale selection and persistence.
- Key-set parity between `de.json` and `en.json` is asserted by the test suite.
