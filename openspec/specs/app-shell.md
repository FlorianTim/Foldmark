# App Shell

## Requirement

Responsive Vue application shell with localized navigation, safe error handling, keyboard-visible
focus, accessible landmarks, persisted language/theme preferences and runtime-safe public
configuration.

The settings menu exposes German/English language selection, local themes, canonical privacy/help
links and confirmed deletion of all app-owned Todo records and UI preferences. The Todo demo renders
only its documented non-HTML Markdown subset.

## Verification

- Automated tests and repository policy checks cover the requirement.
