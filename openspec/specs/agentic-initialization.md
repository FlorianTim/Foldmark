# Agentic Initialization

## Requirement

The initializer reads drafts, derives normative specifications, stops for review after phase 2 by
default, then replaces the demo incrementally.

German raw ideas are translated into an English versioned requirements roadmap during the
specification phase. Reusable concrete-app problems are recorded as sanitized, versioned template
feedback through the repository skill before being proposed upstream.

## Verification

- Automated tests and repository policy checks cover the requirement.
